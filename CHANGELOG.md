## [0.1.0] - 2026-11-07

### Added

- A minimal C# add-on with one ribbon button that opens a welcome window.
- GitHub Actions builds, installer tests and releases, with project details kept in `project.psd1`.
- `scripts/new-project.ps1`, which turns a copy of this boilerplate into your own project.
